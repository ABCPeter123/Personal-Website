# Personal Website

Source for Peter Pu's portfolio, including the project showcase and playground pages.

## Development

This is a static website. Run a local static server from the repository root:

```bash
python -m http.server 8000
```

Open http://localhost:8000.

## Hosting

The current public website is at https://peter-pu-quant-arcade.vercel.app/.

The 3D billiards engine is hosted in a separate Vercel project. The portfolio embeds that engine on the billiards page. The engine's upstream attribution and licensing are described in `ATTRIBUTION.txt`.
